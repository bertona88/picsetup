# PICSetup playground — M0 / M1

The 2026-10-11 agent brief at commit c32f58e102a55ae13cd11c11d312de63ecc8aff5 supplies the later, narrower owner direction for this isolated rebuild. Root documents describe earlier app/ work; operational safeguards still apply. No old implementation is copied. app/, prototype/, production and other Setup projects remain unchanged.

Build a free browser scientific playground: place photonic components, connect ports, edit declared parameters and compare numerical powers and phases. First deliverable is an MZI constructed through ordinary blank-canvas editing, with undo and portable save/reopen. TypeScript, SVG, Vite, Vitest and Playwright are defaults. One coherent CW source, one scalar guided mode per port, linear steady state only. No full-wave, fabrication, calibration, quantum, nonlinear, time-domain or receiver claims.

Layout is presentation only. Drag/rotate/curve changes never change physical length. New links are ideal L = 0 µm. Open data, reusable modules and deployment are later gates. The existing repository license is not changed; MIT is proposed for new code subject to maintainer approval before release.
